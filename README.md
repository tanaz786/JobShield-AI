# 🚀 JobShield AI
> "Don't apply. Verify first."

## 🧠 Problem
Fake job offers and internships are increasing rapidly, especially targeting students, freshers, and job seekers.

Common scam patterns include:
- Registration fees
- Fake HR contacts (WhatsApp/Telegram)
- Unrealistic salary promises

## 💡 Solution
JobShield AI analyzes job descriptions and provides:
- 📊 Risk Score (0–100)
- 🚨 Scam Verdict (Safe / Suspicious / Scam)
- 🧾 Clear explanation of red flags

## ✨ Features
- 🔍 Smart job description analysis
- 🧠 3-layer fraud detection (Groq AI + ML + Rules)
- 📧 Email/domain verification
- 🖼️ Image upload support
- ⚡ Fast, real-time results
